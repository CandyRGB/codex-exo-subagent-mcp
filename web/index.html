profile 使用说明

引用本机已有的 Codex profile；这里不会创建或修改该 profile。是否可用需通过实际任务验证。

接口要求

支持 OpenAI 兼容接口。模型还需支持工具调用，才能执行代理任务。

填写 API 根地址；无需追加 /responses 或 /chat/completions。

认证请求头说明

Authorization 自动使用 Bearer；也支持 X-API-Key。

密钥保存方式

使用当前 Windows 用户加密保存。保存后不回显，也不写入会话记录。

环境变量说明

填写名称，勿填写密钥内容。环境变量需对本地服务进程可见。

模型 ID默认操作
高级设置

按实际部署容量设置。

连接默认思考设置

开启后，留空的项目不发送；关闭后沿用连接默认值。

支持值与默认行为

留空不发送强度；none 与留空含义不同。支持值取决于实际模型和服务。

思考模式与兼容扩展
参数结构说明

标准结构按 Responses / Chat 协议发送强度。扩展结构仅在服务明确支持时使用；原生 Claude / Gemini 协议仍需兼容路由。

模式说明

自适应等模式需要服务支持 thinking 对象。标准结构关闭思考时发送 effort=none。

预算字段说明

标准 effort 没有通用预算字段；扩展结构分别使用 budget_tokens 或 max_tokens。
